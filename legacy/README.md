# Legacy Files

This folder keeps the original v1.x code and recovery data separate from the
v2 app.

- `v1.1.py`: original Tkinter implementation.
- `crypter_v1.2.py`: original PyQt5 implementation.
- `keys.json`: old encrypted key store used only for recovering files encrypted
  by v1.x.

Use the v2 app or CLI from the repo root for new encryption work.
